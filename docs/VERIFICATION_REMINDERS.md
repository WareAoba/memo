# 스케줄 리마인드 검증 · 2026-09-25

- 새 SQLite migration으로 기존 스케줄은 리마인드 꺼짐, 15분 기본값으로 보존한다.
- 생성/수정/상세에 숫자·분/시간/일/주 설정을 연결했다. 시간대 기준 UTC 알림 시각은 서버에서 계산한다.
- 활성 스케줄의 도래한 리마인드를 별도 인덱스로 조회한다. 시작·완료·취소 시 표시 대상에서 제외한다.
- 전역 Toast는 15초 간격과 복귀·연결 복구·스케줄 변경 시 갱신한다. 브라우저 저장소와 Web Locks로 중복을 억제한다. 저장소 불가 시 탭 메모리로 대체한다.
- 테스트: 기본값, 단위 저장, 변경 시 재계산, 잘못된 값·DST 존재하지 않는 시각 거부, 완료/취소/시작 이후 제외, 닫기·재마운트 중복 방지, 변경된 알림, 연결 복구, 숨김 탭·저장소 차단.
- 브라우저: design-reference.html에서 기본 15분, 1시간 입력, 토스트 미리보기의 우하단 배치 확인.
- 실제 개발 서버를 재시작해 migration 적용 후 /api/reminders 200 및 빈 목록 응답 확인.
- 제한: 인앱 알림으로 탭 종료 중 전달 없음. 잠든 탭은 복귀 시 시작 전 알림만 표시. 최대 15초 확인 주기와 네트워크 지연이 있다. Web Locks 미지원 환경에서 여러 탭의 동시 알림 억제는 최선 노력이다.

- 최종 검증: npm run check:backend 통과(format/clippy/tests/build). npm run check:frontend 통과(format/lint/디자인 검사/134 tests/build). 실제 스케줄 추가 모달에서 체크박스와 기본 15분 입력 배치도 확인.
