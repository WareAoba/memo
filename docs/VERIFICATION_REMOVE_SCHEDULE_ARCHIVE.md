# 일정 보관 기능 제거 — 2026-09-25

- 일정 상세의 보관·복원 버튼, 검색 보관 필터·상태 표시, 클라이언트 필드와 보관 API를 제거했다. 캘린더 우상단 검색은 유지한다.
- 일정 DELETE는 405, PATCH archived와 목록 archived/include_archived는 400으로 거부한다. 보관 여부 응답 필드도 제거했다.
- 새 마이그레이션에서 기존 일정의 deleted_at을 비운 뒤 컬럼을 제거한다. 기존 마이그레이션 파일은 변경하지 않았다. 일정·태스크·스냅샷·실행 기록과 사진 데이터는 삭제하지 않는다.
- 일정 취소·재개 기능과 워크/태스크 프리셋의 기존 보관 기능은 별도 기능이다.
- 데이터 이전 회귀 테스트에서 기존 완료 상태·실행 메모·스냅샷 보존, 이전에 숨긴 일정의 목록 포함, 실행 수정, 외래키 무결성을 확인한다.
- 검증: `npm run check:backend` 전체 통과(50개 테스트), `npm run check:frontend` 전체 통과(127개 테스트, 24개 파일). 포맷·린트·빌드 포함.
