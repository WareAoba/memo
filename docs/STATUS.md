# 현재 구현 상태


- 주요 화면의 페이지 라벨은 좌상단, 보기 전환 토글은 같은 줄 우상단으로 통일했다. 검색과 추가 동작은 그 아래에 배치하며 빈 헤더 행을 만들지 않는다. 당일 요약·캘린더는 같은 검색 진입점을 사용한다.
확인일: 2026-09-25. 기능의 현재 상태는 이 문서에서 관리한다. 요구 계약은 [SPEC](../SPEC.md), 경로는 [CODE_MAP](CODE_MAP.md)을 따른다.

## 구현된 범위

- 동작 점검 후속: 자정 이후 메모 자동 저장·갱신 시 실행 초안 유지, 프리셋 승격 후 완료 태스크의 메모·이름 수정, 일정 재개 시 미전송 리마인드 복구를 반영했다.

- UI 종합 점검 후속: 모바일 직접 탐색·이름 우선/시간 접기·월간 일정 수, 텍스트 동작 버튼, 일간 태스크 직접 편집, 실제 본문 스크롤 복구, 모달 퇴장·보기 전환, 자동 저장 상태·접힌 도움말을 반영했다.

- 상시 수동 새로고침 버튼을 제거했다. 저장 후 데이터 갱신은 유지하며, 오류 복구는 텍스트형 다시 시도 버튼으로 제공한다.

- 모바일 월간 캘린더의 숨은 막대 행으로 생기던 내부 스크롤과 태스크 편집의 보관 버튼·메모 겹침을 해소했다.

- 캘린더 일·월·연 공통 배경 패널·제목·화살표 규격, 실제 날짜/월 좌표 기반 확대·축소와 좌우 페이지 전환. 일간 카드 배경·텍스트 좌정렬, 6주 격자 날짜 드롭다운·오늘 이동과 창 내부로 제한한 월 넘김 효과, 월간 막대 좌우 균등 여백·초과 개수 중앙 정렬, 연간 막대 구분색·강조색 채움을 적용했다.

- 일정 작성은 이름 입력 우선, 명시적 프리셋 제안 선택과 접힌 태스크 그룹 탐색을 제공한다. 하단 저장 영역에는 추가될 날짜를 읽기 전용으로 표시한다. 중복 일정 메모·저장 범위 안내를 제거하고 변경·수정·상세 보기 동작을 텍스트로 표시한다.

- 일정의 워크·태스크 이름 직접 입력, 저장 시 숨겨진 프리셋 재사용, 정식 프리셋 등록의 이름 제안·승격 및 기존 일정 상세정보 일괄 적용. 실행 기록은 보존하며 일반 프리셋 수정은 독립 스냅샷을 유지한다.

- 일정·실행 태스크 삭제와 첨부 정리, 모바일 스와이프 삭제 노출, 일정 완료 취소. 네모 일정 체크·원형 태스크 체크, 개별 행 hover 동작. 종료 자정 입력 차단과 기존 자정 종료 편집 초안 보정.

- 시계판 편집의 당일 날짜 숨김, 작은 구분색 점, 공통 편집 팝업 고정 하단 저장 영역. 자정 드래그 누적 제한·저장 직후 Today 갱신·다크 미완료 흰색·연속 일정 호 5단계 외곽 높이.

- 가상 계정 로그인 환경: 기존 로컬 UUID·데이터·사진 경로 보존 마이그레이션, 요청별 사용자 컨텍스트, 계정 확인 API와 프런트 부트스트랩·좌하단 프로필/이름 계정 메뉴와 설정 진입. 선택적 프로필 사진 표시·실패 시 이니셜 대체를 지원한다. `AUTH_MODE=virtual/disabled`. 실제 Google 인증·서버 세션은 후속 범위다.
- 워크·태스크 프리셋, 워크 기본 태스크 연결.
- 일정 생성·수정, 독립 스냅샷, Today·일간/월간/연간 캘린더·일정 검색. 일정·워크·태스크 상세/수정을 통합 편집 팝업으로 제공하며 실행 태스크도 팝업에서 편집한다.
- 태스크 실행값·완료·메모, 일정별 태스크 추가·이름/매개변수 편집.
- 스케줄별 무지개 구분색을 DB에 저장하고 생성·편집에서 선택한다. Today·캘린더 카드의 4px 상단 보더에 적용하며 앱 강조색과 독립적으로 유지한다.
- 카드 hover 시 메모·수정 바로가기, 버튼 중심에 모서리가 겹쳐 확대되는 메모 오버레이, 여백에 따른 모서리 전환·디바운스 자동 저장. 모바일은 카드 메모 오버레이 없이 워크·태스크 편집 팝업에서 메모 자동 저장.
- 선택적 사진, 인앱 리마인드·서버 예약 Web Push·서비스 워커·manifest.
- 공통 디자인 토큰·컴포넌트·디자인 레퍼런스.
- 상세·편집·Today의 중첩 카드 배경을 구분선과 여백으로 정리. Today 단일 본문 스크롤, 화면 비율 기반 일정 모달과 내부 목록의 자연스러운 확장.
- Today는 시계 옆 `요약`과 하단 `오늘의 스케줄`로 구분한다. 둥근 선택 워크 배경·한 줄 태스크 행·하단 레이블형 태스크 추가, 카드별 전체 완료 체크, 빈 안내 제거 및 완료 수만 표시하는 진행률을 적용했다.
- 공통 API Host/Origin 검증, 앱 프레임 삽입 차단, 본문 수신 전 업로드 동시성·시간·사진 저장량 제한. 로그인·세션은 별도 후속 범위다.
- i18next 기반 한국어·영어·일본어 UI, 설정에서 언어 선택·DB 저장, 날짜·요일·오류·기기 알림 번역. [다국어 유지보수](I18N.md).

- 사용자별 DB 앱 설정: 일반·화면·일정·알림·데이터 탭, 자동 저장·즉시 반영·접속/포커스 복귀 시 로드, 테마·크기·시계 단위·강조색·모션·푸시 제어, 범위별 데이터 초기화. 설정 중 기존 메뉴 선택 해제·동일 경로 복귀, 외곽 카드 없는 배치와 공통 드롭다운 적용. [앱 설정](SETTINGS.md).

## 남은 범위

- PWA 오프라인 shell/cache. 서비스 워커가 존재한다고 이 단계 전체가 완료된 것은 아니다.
- Google 로그인·서버 세션·CSRF 및 공개 운영 구성.

## 검증과 이력

- [앱 전역 UI 종합 점검](UI_AUDIT_20260926.md): 9개 기준의 판단, 수정한 레이아웃 결함과 남은 개선 항목.
- 현재 코드의 합격 여부는 `npm run check`로 확인한다. 과거 테스트 개수를 현재 성공 상태로 해석하지 않는다.
- [최근 기능 수정 기록](VERIFICATION_REVIEW_FIXES_20260925.md), [골격 리팩토링 검증](VERIFICATION_AGENT_STRUCTURE.md).
- [구현 계획](IMPLEMENTATION_PLAN.md)은 단계 순서와 과거 완료 기록을 보존한다.
- 상세 기능·운영 문서는 [문서 색인](README.md)에서 선택한다.

- 앱 공통 상단바 중앙의 큰 + 아이콘·“일정 추가” 버튼으로 일정 생성을 통합한다. 일간 캘린더에서는 선택 날짜, 그 외 화면(월간·연간 포함)에서는 앱 시간대의 오늘을 사용한다. 설정 화면에서는 이 버튼을 숨긴다. 화면별 기존 일정 추가 버튼은 표시하지 않는다.
