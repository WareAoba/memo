## 개발 하네스

- 모든 변경의 기록·해시 게이트, Codex 컨텍스트·종료 검사, 로컬 완료 검사·CI 연동. 훅은 사용자 신뢰 승인 후 동작한다. [절차와 제한](AGENT_HARNESS.md).
- 프런트 lint에 구조 검사 연결: 런타임 import 순환, 제품/디자인 진입점에서 도달하지 않는 모듈, UI HTTP·API→UI·route SQL 경계. health의 진단 SQL과 테스트 전용 health 어댑터는 목적을 명시한 예외다.
- 구조 감사 조치와 범위 판단은 [후속 마무리 기록](changes/2026-09-27-audit-followup-finish.md)을 참고한다. 정적 검사는 런타임·시각·성능 검증을 대체하지 않는다.

## 남은 제품 범위

- 병행 알림 목록·확인·재알림 작업은 진행 중이다. include 기반 리마인드 조회와 브라우저 inbox/메뉴 소스가 추가됐으나 이번 UI 작업에서는 통합·실행 검증하지 않았다. [확인 시점](changes/2026-09-27-reminder-concurrent-review.md).

- PWA 오프라인 shell/cache.
- Google 로그인·서버 세션·CSRF 및 공개 운영 구성.

## 검증과 문서

현재 합격 여부는 `npm run check`로 확인한다. 기능·운영 문서는 [문서 색인](README.md), 작업별 실제 검사·실패·미검증은 [최근 변경](CHANGES.md)에서 선택한다. 현재 상태 문서에 테스트 개수와 세부 UI 수정 이력을 누적하지 않는다.

- 콘텐츠 컨텍스트 메뉴: 지정된 카드·태스크·목록·스티커의 우클릭/길게 누르기, 기존 액션 재사용과 상단 직접 색상 팔레트, 포인터 원점 모션, 투명 모달 오버레이와 키보드 탐색. 공통 팝업 퇴장 깜빡임 방지. 미지정 우클릭·휠클릭 차단(휠 스크롤 유지).
