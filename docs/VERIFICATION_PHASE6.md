# Phase 6 검증 — Today·진행률·요건·일정 상세

검증일: 2026-09-24

## 완료 범위

- 당일 요약을 실제 저장 일정으로 교체. 앱 시간대 초기화 후 오늘 날짜 조회.
- 기존 겹침 조회로 여러 날 일정 포함, 날짜/시작 시간/ID 순서 유지.
- 목록 include_details 옵션과 20건 단위 전체 페이지 조회. 상세 스냅샷을 반환하여 일정별 HTTP 요청을 피한다.
- 완료/전체 태스크와 진행률, 건너뜀 별도 표시, 취소 일정의 태스크 집계 제외.
- 사전 연락·공지·이용 가능 시간과 일정 상세 이동. 상세에 워크 선택 정보, 상태, 실행 메모와 저장된 항목 값 표시.
- 로딩·실패·재시도·새로고침·빈 상태, 날짜 변경 시 이전 요청 취소.
- 캘린더 예시는 유지. 실제 Today에는 예시 체크나 저장되는 것으로 오해할 체크 컨트롤을 표시하지 않는다.

## 자동 검사

- Rust fmt, clippy(-D warnings), 테스트 26개, build 통과.
- Prettier, ESLint(경고 없음), Vitest 71개, TypeScript/Vite build 통과.
- 새 회귀: 상세 페이지 조회·날짜 겹침·보관 제외·요건 스냅샷 불변, 21건 전체 조회, 잘못된 응답 거부, Today 시간대 대기·조회 실패 재시도·날짜 변경 경쟁, 완료/건너뜀/취소 구분.
- 기존 개발 서버가 target/debug 실행 파일을 잠가 CARGO_TARGET_DIR=backend/target-phase6으로 백엔드 검사. 해당 빌드 경로는 Git 제외.
- esbuild 프로세스가 샌드박스에서 EPERM으로 차단되어 허용된 권한으로 프런트 검사를 수행했다.

## 브라우저 확인

- 기존 개발 서버의 실행 경로를 확인한 후 검증된 최신 빌드로 재시작했다. 동일 로컬 DB를 유지한다.
- http://127.0.0.1:15173/#/today 에서 저장된 일정 2개, 태스크 0/2 및 실제 이름을 확인.
- 2026-09-24 23:30–2026-09-25 01:05 일정이 날짜 범위와 함께 표시됨.
- 워크 링크 → 일정 상세에서 스냅샷·상태·기존 메모 → 당일 요약 복귀 확인.
- 현재 브라우저 크기의 스크린샷으로 블록/색상/진행률 배치 확인. 별도 모바일 viewport 검증은 이번 단계에서 수행하지 않았다.

## 제한과 다음 단계

- 실행 변경은 Phase 7, 캘린더 실데이터는 Phase 8.
- 진행률은 완료 태스크 수 기준이며 필수 항목의 입력 여부를 완료로 추정하지 않는다.
- 페이지별 읽기는 일관되지만 여러 페이지 전체의 동시 snapshot은 보장하지 않는다. 다른 창에서 바꾼 값은 새로고침으로 반영한다.
- 날짜 겹침은 기존 일정 날짜 필드를 따른다. 서로 다른 일정 시간대 사이의 날짜 변환 조회는 추가하지 않았다.
- 자동 커밋·배포는 수행하지 않았다.
