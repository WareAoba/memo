# Phase 5 UI 조정 검증

검증일: 2026-09-24

## 변경

- 24시간 원판: 위 자정 00시, 오른쪽 06시, 아래 정오 12시, 왼쪽 18시. 자정·정오만 심볼을 표시한다. 보라·주황 파스텔 하루 흐름.
- 시작/종료 선택 버튼, 원판 클릭/터치, 44px 손잡이 드래그, 5분 스냅. 방향키 ±5분, PageUp/Down ±1시간, Home/End 경계 조정.
- '여러 날에 걸친 일정': 시작·종료 날짜와 시간을 직접 입력. 종료 날짜를 실제 저장하며 목록·상세에 표시한다.
- 시간대 입력란 제거. 신규 일정은 앱에 저장된 사용자 시간대, 기존 일정은 기존 시간대를 보존한다. 언어·시간대 설정 메뉴는 추후 구현한다.
- 일정 작성은 날짜·시간 / 워크·태스크·메모로 정리. 워크 선택 후 검색을 접고, 추가 태스크 검색도 펼침 방식으로 정리했다.
- 앱 공통 배경·입력·버튼·탐색·카드·캘린더를 테두리를 줄인 따뜻한 플랫 스타일로 변경했다. 태스크 파스텔 구분과 포커스 표시는 유지했다.
- 새 migration으로 기존 일정의 종료 날짜를 시작 날짜로 채우고 ID·스냅샷·실행값을 보존했다. 기존 migration은 수정하지 않았다.

## 자동 검사

- npm run check:backend 통과: rustfmt / clippy / 25 tests / build.
- npm run check:frontend 통과: Prettier / ESLint / 66 tests / TypeScript / Vite build.
- 추가 회귀: 원판 좌표·5분 스냅·경계, 클릭/포인터 캡처/드래그/취소/키보드/비활성, 앱 시간대·날짜 경계, 여러 날 UI 전환·저장.
- 백엔드: 여러 날 일정과 겹치는 날짜 조회, 역전된 날짜·유효하지 않은 날짜·5분 이외 입력 거부, 종료 날짜 PATCH.
- 기존 5개 migration으로 만든 DB에 일정·워크 스냅샷·태스크 실행 상태·항목 값을 넣고 새 migration 적용 후 보존 및 foreign_key_check를 검증했다.
