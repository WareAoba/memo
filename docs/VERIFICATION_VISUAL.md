# 화면 디자인 정리 — 2026-09-24

- 당일 요약 탐색에 기기의 월·일을 담은 캘린더 아이콘 적용.
- 태스크 6색 전체 채움, 완료 후 색상 유지. 일정과 프리셋 예시에서 같은 태스크 색상 사용.
- 중성 회색 배경, 불투명 표면의 옅은 하이라이트, 모바일 둥근 하단 탐색 적용. 안내 문구와 제목 간소화.
- 참고: [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials). 네이티브 Liquid Glass 구현이 아닌 표면과 탐색 위계의 시각적 참고.

검증: 프런트엔드 포맷·린트·26개 테스트·TypeScript 및 Vite 빌드 통과. 브라우저에서 1280px 당일 요약 및 390px 모바일 일정/캘린더 확인. 모바일 캘린더 가로 넘침 없음, 날짜 버튼 너비 약 45.95px.

다음 단계는 Phase 3 태스크 프리셋의 DB/API 및 등록·편집·보관 UI, 체크/텍스트/숫자 하위 항목과 순서 편집이다. 이후 Phase 4에서 워크 기본 태스크 연결, Phase 5에서 일정 생성과 실행 데이터 저장을 연결한다. 현재 일정과 태스크 체크는 예시이며 새로고침 시 초기화된다.
