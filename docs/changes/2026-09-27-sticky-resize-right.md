# 스티커 크기 조절 우하단 정정

## 변경

- 사용자 정정에 따라 크기 조절 가이드·커서·아이콘을 우하단으로 옮겼다. 오른쪽 드래그는 너비를 늘리고 왼쪽 드래그는 줄이며 위쪽·왼쪽 위치는 고정한다. 기존 크기 제한과 콘텐츠 경계 제한은 유지한다.
- 직전 보관함·상단바 구현과 작업 트리의 다른 변경은 유지했다. 기존 포인터 회귀 검사의 기대값을 새 방향에 맞췄다.

## 문서

- SPEC·STATUS·PRODUCT_GUIDE·DESIGN_SYSTEM·CODE_MAP의 현재 방향 설명을 정정했다. 파일 경로는 바뀌지 않았다. 이전 변경 기록은 당시 이력으로 보존한다.

## 검증

- 최종 diff 검토 및 기록 연결 완료. `npm run check:frontend` 통과(format, lint/design, 51개 파일·253개 테스트, TypeScript/Vite build). 기존 500kB 초과 번들 경고는 남아 있다.
- `npm run check:docs` 통과. 검증 결과 기록 후 다시 연결하고 문서 검사를 재실행한다.
- 백엔드와 저장 형식은 변경하지 않았다. 실제 사용자 데이터는 테스트하지 않는다.
