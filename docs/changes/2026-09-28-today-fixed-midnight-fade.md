# 자정 효과의 도형 끝과 투명화 끝 분리

## 변경

- 기존 미커밋 일정·UI 작업을 보존하고 자정 연속 효과만 변경했다. 사용자 승인에 따라 실제 종료 길이에 묶인 최대 3시간 효과를 고정 범위로 교체했다.
- 자정 이후 도형은 02:00까지 그리되 00:00부터 점진 투명화해 01:30에 완전히 사라진다. 선명/약한/넓은 블러 혼합 후 전체에 최종 smoothstep 감쇠를 적용한다. 그라데이션 끝을 01:30 방사선에 맞춰 두꺼운 호의 안팎과 블러 모두 그 이후 0이 되게 한다. 별도 drop-shadow도 연속 효과에서 제외해 잔상을 막는다.
- 짧게 자정을 넘는 일정도 같은 시각 효과를 사용한다. 다음 날 00:00에 정확히 끝나는 일정은 효과가 없다. 실제 일정의 저장 시간·다음 날 실제 구간·상태색·고정 열·최상단 즉발 막대는 유지한다. API/DB는 변경하지 않았다.

## 문서

- 편집 전 STATUS·CODE_MAP·CHANGES와 직전 레이어 기록, 관련 SPEC·DESIGN_SYSTEM 및 TodayDial/배치/테스트를 확인했다. /design-reference.html#today-dial-reference의 실제 공통 TodayDial을 수정 전후 비교했다.
- SPEC·DESIGN_SYSTEM·STATUS에 02:00 도형/01:30 투명화 계약을 반영하고 CHANGES에 연결했다. 파일 경로는 유지되어 CODE_MAP은 수정하지 않았다.

## 검증

- 선택 테스트 3개 파일 33개 통과. 실제 종료 00:15/02:00/08:00의 도형은 120분으로 같고 다음 날 실제 종료는 보존되는지, 00:00 종료 예외, 최종 마스크의 90분 방사선·0 투명도·블러 적용 순서와 기존 회귀를 확인했다.
- 다크 레퍼런스와 실제 Today에서 자정 꼬리가 부드럽게 사라지는 것을 확인했다. DOM에서 도형 길이 120분·최종 감쇠 끝 90분·추가 filter none을 확인했다. 실제 데이터 저장은 실행하지 않았다. 이번 변경은 라이트/물리 모바일/다른 브라우저 렌더러를 별도 시각 검증하지 않았다.
- 최종 `npm run check:frontend` 통과: 포맷·ESLint·디자인/구조 검사·70개 파일 415개 테스트·TypeScript·Vite 빌드·문서/변경 게이트. 기존 500kB 초과 청크 경고는 유지된다. 백엔드는 수정하지 않아 재검사하지 않았다.
- 최종 diff와 공백 오류를 검토하고 `record:change` 및 `check:docs`를 갱신했다. 개발 서버와 http://127.0.0.1:15173/#/today 및 http://127.0.0.1:15173/design-reference.html#today-dial-reference 탭을 유지한다.
