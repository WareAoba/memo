# 스티커 상단바 정리와 최소화 보관함

## 변경

- 상단바와 좌하단 크기 조절 가이드는 호버 또는 활성 상태에서만 보인다. 바깥 클릭/포커스로 활성 상태를 해제한다. 상단바 레이블과 강조색 상부 띠를 제거하고 연결된 스케줄 색을 상단바 배경에 반영한다.
- 버튼 높이·아이콘·본문·손잡이 여백을 정리했다. 좌하단 크기 조절은 위쪽과 오른쪽 가장자리를 유지한다. 숨겨진 컨트롤의 공간은 유지하여 내용이 움직이지 않는다.
- 최소화된 창은 우하단 보관함으로 들어간다. 위로 펼쳐지는 목록에서 복원하며 제목·내용·위치·크기를 유지한다. 방향키/Home/End/Escape와 바깥 클릭을 지원한다. 설정 화면에서는 보관함도 숨긴다.
- 한국어·영어·일본어 보관함 문구와 메모 데모를 추가했다. 디자인 레퍼런스의 CSS 레이어 순서를 보존하도록 토큰 CSS 뒤에서 데모를 가져온다.
- 기존 스티커 구현과 다른 UI·문서 하네스 변경은 작업 시작 전부터 공유 작업 트리에 있었다. 해당 변경은 [기존 변경 기록](2026-09-27-documentation-harness.md)에 구분되어 있으며 이번 작업에서 되돌리지 않았다. 저장 스키마와 백엔드는 변경하지 않았다.

## 문서

- SPEC·PRODUCT_GUIDE에 활성 표시와 보관함 계약을 반영했다.
- STATUS에 구현 상태, CODE_MAP에 StickyTray 경로, DESIGN_SYSTEM에 크기·색·레이어·모션 규칙을 기록했다.
- CHANGES에 이번 기록을 연결했다. 기존 하네스 기록과 검증 주장은 이 작업의 실행 결과와 구분한다.

## 검증

- 스티커 선택 테스트 2개 파일·10개 테스트 통과. 활성 전환, 색 변경, 좌하단 리사이즈, 최소화 저장 및 키보드 복원을 검증했다.
- `npm run check:frontend` 통과: format, lint/design, 51개 파일·253개 테스트, TypeScript/Vite build. Vite의 500kB 초과 chunk 경고는 남아 있다.
- `npm run check:docs`의 문서 링크와 변경 기록 검사 통과. 최종 diff를 확인하고 이 기록을 연결한 뒤 문서 검사를 재실행한다.
- 브라우저의 메모리 전용 디자인 데모에서 메모 입력 → 최소화 → 위로 열리는 보관함 → 내용 복원을 확인했다. 실제 사용자 DB는 테스트에 사용하지 않았다.
- 백엔드는 변경하지 않아 전체 백엔드 검사와 실제 일정 데이터 조작은 수행하지 않았다.
