# 당일 요약 상태 피드백 수정

## 변경

- 기존 선택적 시각·여러 날 입력·macOS 환경 변경을 보존했다. 이번 변경은 Today 상태 표현·태스크 추가 노출/간격과 관련 회귀 테스트다.
- 다크 토큰의 예정 짙은색·미완료 흰색을 흰색·빨강으로 바로잡고 진행 중 노랑과 완료 초록을 선명하게 했다. 초록의 배경 혼합을 제거하고 채도 토큰을 공유한다. 라이트 기존 색상은 유지한다.
- 완료 판단을 시간 구간보다 먼저 수행한다. 시작 전/진행 중 완료도 즉시 초록이며 취소하면 시간 상태로 복귀한다. 시작만 있는 막대도 같은 상태색을 사용한다. Today의 기존 저장 성공 상세 반영 경로를 사용하며 API/DB/추가 조회는 변경하지 않는다. DB 부하 실측은 하지 않았고 이번 재현 원인은 프런트 조건 순서다.
- 카드의 hover/focus/선택/추가 중에 태스크 추가를 표시한다. 44px 조작 영역을 유지하면서 버튼 위 12px 여백을 없애고 카드 여백을 위 12px·아래 8px, 태스크 위 간격을 8px로 줄였다.
- 실제 TodayDial 네 상태 예시를 디자인 레퍼런스에 추가했다.

## 문서

- SPEC·DESIGN_SYSTEM에 상태색·완료 우선순위·hover/간격 계약, STATUS에 시작만 상태색 표시, TASK_CUSTOMIZATION에 추가 버튼 흐름을 반영했다. 신규 소스 경로는 없어 CODE_MAP은 변경하지 않았다. CHANGES에 연결했다.
- 참조: shared/ui.tsx의 Button/Input/Surface, IconButton, design-reference.tsx의 completion-reference와 공통 버튼 상태. 기존 태스크 입력 NewTaskRows를 유지했다. 추가 색상 예시는 /design-reference.html#today-dial-reference이다.

## 검증

- 선택 검사: Today·TodayDial·scheduleAppearance 32개 통과. 시작 전/진행 중/종료 후 완료 우선순위, 막대와 호의 완료/취소, hover/focus 및 추가 중 유지, 추가 조회 없는 성공 응답 반영을 검증했다. 첫 실행은 새 테스트의 닫기 버튼 번역 기대값 1건이 틀려 실패했고 실제 레이블로 정정했다.
- 첫 전체 검사는 포맷/lint/구조 검사와 401개 테스트를 통과한 뒤 새 테스트의 프리셋 목록 mock 타입 오류로 빌드 실패했다. 실제 페이지 응답 형태로 수정했다. 재검사 결과는 아래에 기록한다.
- 브라우저: 다크 레퍼런스에서 흰/노/빨/초 호와 범례, 완료/미완료/disabled 체크를 확인했다. 라이트 레퍼런스의 기존 흰/연노랑/연빨강/초록도 실제 호의 계산 색과 범례로 확인했다. 제품 1280×900 키보드 포커스와 390×844 선택 상태에서 추가 버튼을 확인했다. 카드 padding 12px 16px 8px·버튼 위 margin 0px·버튼 높이 44px를 실측했다. 화면 크기는 복원하고 제품 /#/today 및 레퍼런스 탭과 기존 개발 서버를 유지했다. 실제 저장 데이터는 변경하지 않았다. hover는 회귀 테스트로 검증했고 실제 포인터 hover만의 시각 검증과 OS 모션 축소는 미실시다.
- 최종 `npm run check:frontend` 통과: 문서/변경 게이트, 포맷, ESLint·디자인·구조 검사, 69개 파일 401개 테스트, TypeScript·Vite 빌드. 기존 500kB 초과 청크 경고는 남아 있다. 이번 작업에서 백엔드 코드는 변경하지 않아 백엔드 검사는 재실행하지 않았다.
- 최종 diff와 공백 오류를 검토했다. 확인 주소는 http://127.0.0.1:15173/#/today 및 http://127.0.0.1:15173/design-reference.html#today-dial-reference 이며 두 화면을 유지한다.
