# 즉발 막대 최상단과 자연스러운 자정 블러

## 변경

- 기존 미커밋 환경·일정·태스크·Today 수정은 보존했다. 이번 작업은 직전 투명 경계의 적용 대상과 그리기 순서, 블러 혼합만 변경한다.
- 즉발 막대를 SVG 마지막 레이어로 이동해 호·블러·현재 시각 바늘보다 위에서 끊김 없이 표시한다. 막대에는 외곽 마스크를 적용하지 않고, 아래 선명한 호와 블러에는 막대 전체 폭+0.8 단위 여백을 비운다.
- 선명한 호의 경계 마스크와 블러용 막대 마스크를 분리했다. 블러는 자기 자신이나 다른 호의 얇은 외곽 마스크로 잘리지 않는다.
- 선명한 선과 2.5/6 단위 Gaussian blur를 곡선 감쇠 그라데이션으로 혼합한다. 마스크 적용 뒤 블러를 처리해 가장자리와 끝부분도 부드럽게 퍼진다. 기존 최대 3시간/실제 종료 중심선·고정 열·상태색·다음 날 선명한 표시는 유지한다. DB/API는 변경하지 않았다.

## 문서

- 편집 전 STATUS·CODE_MAP·CHANGES 및 관련 SPEC·DESIGN_SYSTEM·직전 투명 경계 기록을 확인하고 TodayDial/TodayDialSeparation 실제 구현과 /design-reference.html#today-dial-reference의 교차·자정 예시를 확인했다. 제품과 레퍼런스가 같은 실제 컴포넌트를 사용한다.
- SPEC·DESIGN_SYSTEM·STATUS를 현재 레이어/블러 계약으로 갱신하고 CHANGES에 연결했다. 파일 경로는 그대로여서 CODE_MAP은 수정하지 않았다.

## 검증

- 선택 테스트 TodayDial·todayDialLayout·Today: 3개 파일 33개 통과. 막대가 마지막 레이어이고 마스크 조상이 없으며 아래 호에만 전체 폭의 공백을 만드는지, 블러 마스크에 호 외곽이 없는지, 감쇠 방향과 필터 적용 순서, 기존 상태/겹침/자정 동작을 검증한다.
- 다크 레퍼런스와 실제 Today에서 교차 막대가 끊기지 않고 자정 블러의 외곽 절단선이 사라짐을 확인했다. 실제 데이터 쓰기는 실행하지 않았다. 라이트 레퍼런스에서도 막대/블러를 확인하고 다크로 복원했다. 물리 모바일·다른 브라우저 렌더러는 미검증이다.
- 최종 `npm run check:frontend` 통과: 포맷·ESLint·디자인/구조 검사·70개 파일 415개 테스트·TypeScript·Vite 빌드·문서/변경 게이트. 기존 500kB 초과 청크 경고는 유지된다. 백엔드는 변경하지 않아 재검사하지 않았다.
- 최종 diff 검토와 `git diff --check` 후 기록을 연결하고 `npm run check:docs`를 통과했다. 개발 서버와 http://127.0.0.1:15173/#/today 및 http://127.0.0.1:15173/design-reference.html#today-dial-reference 화면을 유지한다.
