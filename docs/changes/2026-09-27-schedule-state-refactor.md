# 2026-09-27 구조 감사 후속 1차: 생성 초안·완료 동작 정리

## 변경

[최근 감사](2026-09-27-code-structure-audit.md)의 권장 순서 1과 2 중 생성 초안 상태 분리를 수행했다.

- ScheduleEditor의 생성 태스크 상태·기본 목록 조회·행 수정·검증·저장 변환을 useScheduleTaskDraft로 분리했다. rowKey/source/name/parameters/execution_notes를 같은 행에서 관리한다. 이름 변경 시 매개변수는 새 기본값으로 초기화하지만 메모는 보존한다.
- 워크 변경·조회 실패/재시도에서 수동 초안을 유지한다. 늦게 도착한 이전 워크 응답은 무시한다. 기본 목록과 겹치는 수동 행은 수동 입력을 우선한다.
- 중복 ID/이름의 별도 행이 매개변수·메모를 공유하지 않게 했다. 중복 상태에서 저장하면 안내하고 전송을 막으며, 한국어·영어·일본어 문구를 추가했다. 서버 중복 제거 계약은 변경하지 않았다.
- scheduleCompletion의 공통 동작을 Today·일간 카드·상세 편집·스티커에 연결했다. 상세의 PATCH /status 사용을 POST /complete로 바꿨다. 해제는 /reopen, 취소 일정 잠금·실패 시 기존 상태·화면별 mutation lock은 유지한다.
- 훅 회귀(실패/재시도·응답 경합·중복 행 격리), 편집 화면 회귀, 동일 fixture 기반 네 화면 완료/실패/취소 잠금 비교 테스트를 추가했다. 화면 테스트는 API mock 경계이며 실제 HTTP/서버 통합 실행의 증명은 아니다.
- 시작 시 존재한 미커밋 UI·다국어·스티커·문서 하네스 변경은 이전 작업이다. 수정한 기존 파일의 해당 변경을 유지했으며 이번 성과로 집계하지 않는다. 새 백엔드·DB·CSS 변경은 없다.

## 문서

- SPEC·TASK_CUSTOMIZATION: 초안 보존·중복 저장 차단·공통 완료 체크 계약을 반영했다.
- STATUS: 구현된 1차 범위, CODE_MAP: 새 상태/완료 모듈과 테스트 경로, CHANGES: 이번 기록 링크를 추가했다.
- DESIGN_SYSTEM·I18N: 기존 공통 UI와 번역 규칙을 그대로 사용하므로 기준 변경이 없다.
- 후속 범위: 도메인 변경 이벤트/조회 공유·월연간 요약 조회·CSS 소유권 통합/시각 검증·App 라우팅 상태·백엔드 반복 조회/DTO·미사용 모듈/구조 검사는 미구현이다. 이번 작업을 감사 전체 해결로 해석하지 않는다.

## 검증

- 선택 프런트 검사 최초 실행은 샌드박스의 esbuild spawn EPERM으로 시작하지 못했다. 권한 확장 재실행에서 3개 파일 33개 테스트 통과. 이후 편집 화면 회귀 2개를 추가했으며 아래 전체 검사에 포함해 통과했다.
- npm run check:frontend: 통과. Prettier·ESLint/design 검사, 54개 파일 274개 테스트, TypeScript·Vite build 성공. 기존 500 kB 초과 경고는 남는다(JS 569.19 kB, gzip 173.01 kB).
- CARGO_TARGET_DIR=backend/target/review에서 npm run test:backend -- --test execution: 14개 통과. 실제 데이터 대신 테스트 임시 DB로 완료 원자성·필수값·완료 취소·스냅샷 격리를 확인했다. 감사 때 기본 실행 파일 잠금 문제가 있어 기존 review 빌드 경로를 사용했다.
- git diff --check: 통과(기존 문서의 CRLF/LF 정규화 경고만 있음). 최종 제품 diff와 새 모듈·테스트·문서를 검토했다.
- record:change 최초 실행은 샌드박스의 spawnSync git EPERM으로 실패했다. 권한 확장 재실행으로 이번 범위의 19개 파일을 연결했다. check:frontend의 문서 게이트에서 Markdown 46개 링크와 변경 파일 106개 기록 검사를 통과했다. 이 결과 갱신 후 기록·check:docs를 다시 수행한다.
- 실제 브라우저 시각 검사·원격 CI·실운영 데이터·백엔드 전체 검사는 수행하지 않았다. 레이아웃/CSS와 서버 구현은 변경하지 않았다.
