# 시간 원판 클릭 모션과 회전 영역 수정

## 변경

- 원판을 누르기만 해도 dragging 상태가 켜져 클릭 이동의 460ms 회전이 생략되던 문제를 수정했다. 포인터가 다른 시간 위치로 움직일 때만 즉시 반영하며 정지한 포인터·클릭은 기존 호/손잡이 회전을 사용한다.
- 원판 크기의 투명 손잡이 회전 영역이 대각선에서 원판 밖으로 커지는 것을 원판 경계의 overflow: clip으로 제한했다. 조작 중 상위 스크롤 영역이 늘어나는 것을 막고 원판 안의 손잡이·포커스·그림자는 유지한다.
- 기존 미커밋 변경 전체 중 TimeDial.tsx·인접 테스트·schedules.css의 기존 diff를 확인했다. 이전 작업의 시간 박스 펼침·호/손잡이 모션·태스크 밀도 변경은 보존하며 이번 수정과 구분한다. API·저장 데이터는 변경하지 않았다.

## 문서

- 지정 레퍼런스 /design-reference.html#date-time-reference, 실제 TimeDial·shared/ui.tsx와 schedules.css, SPEC의 Phase 5 UI 및 시간 모션 계약, PRODUCT_GUIDE, 이전 시간 팝업·UX 개선 기록을 확인했다.
- 기존 계약(호/손잡이 함께 보간, 직접 드래그 즉시 반영, 크기 유지)을 복구하므로 SPEC·STATUS·DESIGN_SYSTEM은 변경하지 않는다. 신규 코드 경로가 없어 CODE_MAP도 유지한다. CHANGES에 이 기록을 연결한다.

## 검증

- TimeDial 선택 검사 9개 통과. 클릭/정지 포인터에는 모션 유지, 실제 드래그에서만 즉시 반영, 취소 시 복귀를 기존 포인터·자정 경계 회귀에 추가했다.
- 기존 localhost:15173 페이지의 모바일 회전 영역은 원판 335.2px보다 큰 465.65px로 측정됐다. 해당 서버에는 현재 파일 수정이 반영되지 않아 현재 작업 폴더의 Vite를 http://127.0.0.1:5173/에 실행했다.
- 수정 후 390×844 레퍼런스에서 overflow: clip 반영, 클릭 전후 원판 335.2×335.2px·레퍼런스 섹션 348.8×935px 유지 확인. 클릭 직후 목표 178.75도와 중간 transform matrix(약 83.75도)가 달라 실제 회전 보간을 확인했다. 실제 데이터는 사용하지 않았다.
- 1280×900 데스크톱에서도 시간 박스 펼침·키보드·손잡이 드래그(종료 23:55 경계) 후 원판 420×420px·섹션 1072×991.8px 유지 확인. 임시 뷰포트는 원복하고 현재 레퍼런스 탭과 5173 서버를 유지했다. 화면은 저장소 밖 visualizations의 time-dial-fixed.png에 저장했다.
- 전체 `npm run check:frontend` 통과: 포맷·lint·디자인/구조, 68개 파일 379개 테스트, TypeScript 및 배포 빌드. 기존 500kB 초과 번들 경고는 유지된다. 실제 터치 기기와 OS 모션 설정 변경은 미검증이며 기존 축소 CSS는 유지했다.
- 최종 diff 확인 및 기록 연결 후 `npm run check:docs` 통과(70개 Markdown 경로, 283개 변경 파일 기록). 백엔드는 변경하지 않아 재검사하지 않았다.
