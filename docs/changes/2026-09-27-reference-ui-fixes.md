# 레퍼런스 테마와 공통 UI 수정

## 변경

- 레퍼런스 상단에 해·달·모니터 아이콘과 테마 선택을 추가했다. 앱 SettingsProvider의 시스템 테마 반영을 useTheme으로 추출해 레퍼런스와 공유한다.
- tokens.css의 라이트/다크 success/warning/danger 및 soft 배경 채도·명도를 강화했다. 공통 체크, 오류/위험 버튼, 경고 등 기존 토큰 소비자에 자동 반영된다. 강조색 및 일정 구분색 팔레트는 독립적으로 유지한다.
- DetailKindInput의 포커스 테두리를 화살표 포함 전체로 옮기고 화살표 hover 배경을 제거했다. 입력 클릭마다 열던 처리를 toggle로 바꿨다. WorkEditor, TaskPresetEditor, PresetItemsEditor 등의 실제 공통 입력 사용 지점을 검색했다.
- ToastRegion의 스크롤 클리핑 경계 안에 그림자 여백을 확보했다. 실제 Toast/ToastRegion을 레퍼런스가 직접 사용하므로 별도 예시 CSS가 없다.
- 선행 작업의 대규모 미커밋 변경과 진행 중 콘텐츠 메뉴/팝업 모션 변경이 있다. 기존 DisclosureIcon, MenuSurface, usePopupState의 변경을 보존하며 현재 공통 toggle를 입력과 화살표에 연결했다. 이번 작업은 백엔드·DB를 변경하지 않는다.

## 문서

- DESIGN_SYSTEM에 공유 테마, 상태 토큰, 입력 포커스/토글, 토스트 그림자 계약을 추가했다. CODE_MAP에 공통 테마 훅과 회귀 테스트 경로를 추가하고 CHANGES에 연결했다. 기존 SPEC의 테마/공통 컨트롤/알림 계약 내의 수정이므로 SPEC·STATUS의 기능 범위는 변경하지 않았다.

## 검증

- 선택 테스트 3개 파일 12개 테스트 통과: 입력/화살표 재클릭, 키보드 선택·직접 입력·Escape, 고정 드롭다운 반복 토글, 앱 시스템 테마 변경.
- 포맷, lint/디자인/구조, 전체 61개 파일 338개 테스트, TypeScript·Vite 빌드 통과. 첫 전체 테스트는 focus만으로 목록이 열린다고 가정한 editorRegression 1건이 실패했다. 클릭 또는 키보드로 열도록 변경된 동작에 맞춰 클릭 이벤트로 수정한 후 전체 통과했다. Vite의 기존 500kB 초과 번들 경고는 남는다.
- 브라우저에서 라이트/다크/시스템 토글, 공통 종류 입력과 고정 그룹의 재클릭 닫힘, 입력+화살표 외곽선, 투명 화살표, 토스트 20px 모서리와 32px 그림자 여백을 확인했다. 390px 모바일에서 가로 넘침 없음(scrollWidth 381px). OS 선호 변경 구독은 기존 Settings 테스트가 검증한다. 실제 OS 설정 변경과 실제 터치 기기는 미검증이다.
- git diff --check 통과. 진행 중인 별도 콘텐츠 메뉴/스티커 작업 파일의 미기록 변경으로 전역 check:docs/check:frontend 게이트가 막힐 수 있다. 이번 기록에는 검토한 이 작업 파일만 연결하며 다른 작업 파일의 해시는 승인하지 않는다. 프런트 검증 명령은 개별 실행했다.
