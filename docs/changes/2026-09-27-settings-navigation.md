# 설정 탐색과 공통 컨트롤

## 변경

- 사용자 요청으로 설정 탭을 데스크톱/모바일 모두 왼쪽 세로로 이동했다. 공통 VerticalTabs는 선택 배경 이동, 순서에 따른 위/아래 본문 진입, 키보드 탐색과 별도 본문 스크롤을 제공한다. 기존 수평 설정 CSS와 중복 레이아웃을 제거했으며 CSS import 순서는 유지한다.
- DropdownSelect에 장식 슬롯을 추가해 테마 목록/현재 값에 기존 sun/moon/monitor를, 강조색 목록/현재 값에 실제 테마별 색상 샘플을 표시한다. 문자열 레이블과 검색/접근성 계약은 유지한다.
- ui.tsx에 네이티브 checkbox 기반 ToggleSwitch를 만들고 레퍼런스에 먼저 등록한 뒤 푸시 계정 설정에 연결했다. 회색/성공색 배경, 원형 손잡이 이동, 44px 조작 영역, 포커스/disabled와 모션 축소를 제공한다. 푸시 권한/기기 구독·서버 저장 계약은 그대로다.
- 선행 대규모 미커밋 변경은 보존했다. 트랙 이름 전달, 저장 중 문구 정리, 공유 팝업/펼침/메뉴·스티커·테마 레퍼런스 변경은 기존 작업이며 이번 작업과 구분했다. 백엔드·실제 데이터는 수정하지 않았다.

## 문서

- SPEC·SETTINGS의 수평 탭 계약을 세로 탐색으로 갱신했다. DESIGN_SYSTEM에 공통 패턴/상태, STATUS에 구현 범위, CODE_MAP에 신규 컴포넌트 경로를 반영했다. CHANGES에서 연결한다.
- 편집 전 레퍼런스 /design-reference.html의 테마·DropdownSelect 선택/펼침 상태와 실제 ui.tsx, ActionIcon, DropdownSelect, 디자인 CSS/토큰을 확인했다. 신규 기준은 #settings-controls-reference이며 제품과 같은 VerticalTabs·ToggleSwitch를 사용한다.

## 검증

- 선택 검사: Settings·DropdownSelect 10개 통과 후 스위치 실패/재시도·로드 잠금·양방향 키보드 회귀 추가, Settings 9개 통과.
- ESLint·디자인·구조 검사 통과. 전체 완료 검사는 아래에 최종 결과를 기록한다.
- 브라우저 실제 설정 데스크톱과 390×844 모바일에서 세로 탭·본문·강조색 목록을 확인했다. 모바일 document scrollWidth와 innerWidth 모두 390으로 가로 넘침 없음. 레퍼런스 스위치 꺼짐/켜짐·disabled 양쪽 상태, 키보드 Space 전환을 확인했다. UI 도구의 체크 클릭 확인은 한 차례 상태 확인에 실패했으며 이후 키보드와 포인터 입력을 따로 확인했다. 실제 푸시 전송과 터치 기기는 검사하지 않았다.
- 최종 `npm run check:frontend` 통과: 문서/기록 게이트, 포맷, ESLint·디자인·구조, 61개 파일 340개 테스트, TypeScript와 Vite 빌드. 기존 500kB 초과 번들 경고만 남는다. 백엔드는 변경하지 않아 재실행하지 않았다.
- 레퍼런스 밝은/어두운 테마, 모바일 실제 알림 스위치와 스크롤, Home/End 이동을 추가 확인하고 임시 뷰포트를 복원했다. 실제 OS 모션 설정 변경과 프레임별 모션 분석은 미검증이며 CSS 미디어 쿼리·기존 SettingsProvider 선호 반영 회귀로 보완한다.
- 최종 변경분을 작업 전 사본과 비교하고 `git diff --check`를 통과했다. 기록 전 게이트는 이번 작업의 18개 미기록 파일만 보고했으며 기록 후 통과했다. Windows rg의 와일드카드 경로 검색 1회는 경로 문법 오류였고 코드 검사 실패가 아니다.
