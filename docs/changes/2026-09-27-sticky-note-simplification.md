# 자유 메모와 보관함 간소화

## 변경

- 기존 스티커 생성·삭제/지니 모션, 트랙 격리, 설정 UI 작업 위에서 요청한 세 가지 표현을 수정했다. 기존 다른 변경은 보존했다.
- 자유 메모의 제목 입력을 제거하고 본문 입력만 유지한다. 과거 제목 데이터는 삭제하지 않고 기존 목록·접근성 식별에 보존한다. 새 메모는 보관함과 관리 목록에서 본문 앞부분으로 찾는다.
- 우하단 버튼의 레이블·개수·화살표를 제거하고 공통 ActionIcon에 곡선 종이 가장자리와 말린 모서리의 sticky SVG를 추가했다. 44px 조작 영역과 접근 가능한 이름·툴팁은 유지한다.
- 보관함 맨 위에 공통 plus 아이콘과 스티커 추가 항목을 넣고 기존 대상 선택 생성 모달로 연결한다. 빈 목록에서도 사용 가능하며 기존 팝업 퇴장 후 열린다. 한국어·영어·일본어 문구를 추가했다.
- 레퍼런스 StickyDemo에도 같은 메뉴 콜백을 연결한다. 미리보기는 단일 창을 다시 열고 제품은 기존 생성 모달로 여러 창을 생성한다.

## 문서

- SPEC, PRODUCT_GUIDE, DESIGN_SYSTEM, STATUS와 CHANGES를 갱신했다. CODE_MAP은 기존 경로·소유 구조가 그대로여서 수정하지 않았다.
- 참조 구현: shared/ui.tsx의 Button·Textarea·MenuSurface·MenuOption, ActionIcon.tsx, StickyTray.tsx·StickyWindow.tsx·StickyDemo.tsx. 편집 전 /design-reference.html#sticky-demo에서 입력과 보관함 기본·열림 상태를 확인했다.

## 검증

- StickyWorkspace 선택 테스트 10개 통과: 기존 저장·복원·트랙·이동 회귀 및 빈 보관함 추가→생성→본문 편집→최소화→복원.
- 브라우저 레퍼런스에서 제목 입력 제거, 아이콘 전용 버튼, 빈 보관함 추가 항목과 키보드 포커스·Escape 복귀·추가 클릭 후 메뉴 퇴장을 확인했다. 기본 데스크톱과 390×844 모바일의 어두운 테마를 확인했고 뷰포트를 복원했다. 별도 밝은 테마·모션 축소의 브라우저 재검증은 하지 않았다(관련 기존 자동 회귀는 전체 검사에 포함).
- npm run check:frontend 통과: 문서·기록 게이트, 포맷, ESLint·디자인·구조, 61개 파일 341개 테스트, TypeScript·배포 빌드. 기존 500kB 초과 번들 경고는 남아 있다. git diff --check 통과.
- 초기 포맷 실행에서 ActionIcon 파일 쓰기가 일시 실패했고 재실행은 성공했다. 초기 문서 편집 호출은 도구 구문 오류로 적용되지 않았으며 수정 후 성공했다.
- 실제 터치 기기·서버 데이터 쓰기는 검증하지 않았다. 백엔드 변경 없음.
