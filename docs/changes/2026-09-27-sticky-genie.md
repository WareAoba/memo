# 스티커 메모 명칭과 지니 효과

## 변경

- 우하단 수납 버튼의 표시·접근성 이름을 스티커 메모(Sticky / 付箋)로 통일하고 보관함 접미사를 제거했다. 한국어 생성 버튼도 스티커 메모 띄우기로 명시했다.
- 최소화·목록 복원 시 실제 수납 버튼 위치로 아래쪽부터 휘어 모이는 지니 효과를 추가했다. 입력값·스크롤을 복사한 비대화형 스냅샷을 사용하며 데이터 상태 저장은 애니메이션을 기다리지 않는다. 복원은 역방향이며 종료·취소 시 복제 화면을 정리한다.
- 모션 축소·끄기 및 OS 선호에서는 효과 없이 전환한다. 기존 우하단 리사이즈·상단바·수납 목록과 작업 트리의 다른 변경은 보존했다.

## 문서

- SPEC·STATUS·PRODUCT_GUIDE·DESIGN_SYSTEM에 명칭·전환 효과를 반영하고 CODE_MAP에 효과 구현 경로를 추가했다.

## 검증

- 선택 검사: 스티커 3개 파일·14개 테스트 통과. 스냅샷 접근성·내용 보존, 완료·취소 정리, 모션 설정 생략을 포함한다.
- 브라우저의 메모리 전용 디자인 데모에서 최소화·목록 복원을 확인했다. 실제 사용자 데이터를 테스트에 사용하지 않았다.
- 첫 전체 검사에서 257개 테스트는 통과했으나 새 효과와 테스트의 엄격한 타입 검사 두 곳이 실패했다. 복사 대상의 존재 검사와 Promise 타입을 명시하여 수정 후 전체 검사를 다시 실행한다. 백엔드 변경은 없다.
- 수정 후 `npm run check:frontend` 통과: format, lint/design, 52개 파일·257개 테스트, TypeScript/Vite build. 기존 500kB 초과 번들 경고는 남아 있다. `npm run check:docs`의 링크·변경 기록 검사도 통과했으며 최종 기록 연결 후 재확인한다.
