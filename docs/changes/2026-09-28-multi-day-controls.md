# 여러 날 입력과 레퍼런스 전환 보완

## 변경

- 여러 날 입력에서는 시각을 지정하기 전에도 시작/종료 시각 칸과 부터/까지를 모두 표시한다. 종료부터 입력할 수 있으며 최종 저장의 종료만 지정 금지 계약은 유지한다. 기본 시계판의 순차 입력은 유지한다.
- 레퍼런스에 제품과 같은 Input 체크박스의 여러 날에 걸친 스케줄 전환을 넣었다. 체크를 끄면 시계판, 켜면 날짜 범위가 표시되며 시간 초안과 기본 모드의 자정 통과 계산을 유지한다.
- 앞선 macOS 설정·자정 통과·선택적 시간·배치 교정 변경은 보존했다. 이번 작업은 ScheduleDateRange, 레퍼런스, 인접 회귀와 문서만 수정한다.

## 문서

- SPEC·DESIGN_SYSTEM의 모드별 초기 입력과 레퍼런스 전환 계약, STATUS 구현 범위, CHANGES를 갱신했다. CODE_MAP은 경로 변경이 없어 유지했다.
- 편집 전 DESIGN_SYSTEM, 실제 ScheduleDateRange/TimeEndpoint/TimeDial 및 제품의 Input 체크박스와 레퍼런스 화면을 확인하고 같은 컴포넌트를 재사용했다.

## 검증

- 미지정 여러 날 일정에서 양쪽 입력 표시·종료 먼저 선택 후 시작 선택·저장 회귀를 추가했다. 선택 테스트 25개와 최종 `npm run check:frontend` 모두 통과했다(포맷·lint·디자인/구조·394개 테스트·TypeScript·빌드). 기존 JS 청크 크기 경고는 남아 있다.

- 실제 레퍼런스에서 체크 해제 시 기본 시계판, 체크 시 날짜 범위 전환을 확인했다. 새로고침한 초기 여러 날 모드에 시작/종료의 지정 없음 입력이 모두 보이는 것을 확인했다. 개발 서버와 http://127.0.0.1:15173/design-reference.html#date-time-reference 탭을 유지했다. 실제 데이터 쓰기는 하지 않았다. 최종 diff/공백 확인 후 기록과 문서 게이트를 갱신했다.
