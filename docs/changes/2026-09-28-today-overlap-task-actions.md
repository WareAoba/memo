# 시계판 겹침·자정 연속과 태스크 동작 정리

## 변경

- 기존 미커밋 환경·선택 시각·여러 날·Today 색상/완료 작업을 보존했다. 이번 작업은 랜덤 높이 제거, 구간별 겹침, 단발 상태, 자정 이후 표현, 작은 태스크 버튼과 실행 편집 동작 제거다.
- todayDialLayout은 날짜별 실제 호와 다음 날 연속 구간을 구성하고 겹침 경계에서만 분할한다. 독립 구간은 28px 전체 두께, 겹치는 부분은 동시 개수로 2/3열 등을 만든다. 입력 순서와 무관하게 정렬하며 맞닿기·단발 막대는 겹침 폭을 소비하지 않는다. 날짜/일정이 같으면 매초 계산을 재사용한다.
- 자정 이후는 실제 종료까지 최대 3시간의 호를 남기며 투명도와 블러를 점진 적용한다. 00:00 종료에는 꼬리가 없고 다음 날 실제 호는 선명하게 표시한다. 여러 날 일정은 계속됨을 알리는 최대 3시간 표현이다. 정적인 효과로 모션 설정에 따른 반복 애니메이션은 없다.
- 시작만 있는 막대는 일정 시간대의 지정 시각 전 흰색, 해당 시각부터 미완료 빨강, 완료 초록으로 처리한다. 시간 전체 미지정은 시간 경과로 미완료 처리하지 않는다.
- 공통 task-hover-actions에서 정밀 포인터·데스크톱 버튼을 32px/아이콘16px로 줄이고 모바일·터치44px를 유지한다. 태스크 삭제 버튼은 기본/hover 모두 배경 없이 danger 아이콘을 사용한다. 기존 삭제 확인·잠금·실패 보존·모바일 스와이프는 유지한다.
- TaskExecution의 시작·완료/완료 취소·건너뛰기/취소 상태 조작 행, 전용 dirty/memoPending 연결·상태 문구, 미사용 play/skip 아이콘·번역을 제거했다. 완료는 카드 체크로 통일한다. 시작 날짜의 레이블로도 쓰는 시작 번역과 기존 데이터/공유 실행 API는 보존한다. 서버·DB·migration은 변경하지 않았다.

## 문서

- SPEC·DESIGN_SYSTEM·STATUS·TASK_CUSTOMIZATION에 현재 동작을 반영하고 CODE_MAP에 todayDialLayout과 인접 테스트를 안내했다. CHANGES에 연결했다.
- 편집 전 DESIGN_SYSTEM 및 실제 Button/Input/Surface·IconButton·DeleteButton·MemoButton을 확인했다. /design-reference.html#today-dial-reference에서 겹침/자정/단발 예시를 확장하고 #task-actions-reference에 실제 공통 버튼의 기본·포커스·disabled 예시를 추가했다.

## 검증

- 선택 검사에서 48개 통과·Today 갱신 회귀 1개 실패: SVG 구간 그룹 추가로 기존 직접 자식 selector가 깨져 후손/closest selector로 수정했다. 두 번째 실행은 동일 테스트의 부모 title 접근 기대가 남아 실패하여 함께 교정했다. 기존 제품 동작 실패로 분류하지 않는다.
- 첫 전체 검사에서 70개 파일 411개 테스트·포맷·lint·구조 검사가 통과했으나 테스트의 Testing Library 옵션에 Playwright 전용 exact를 사용한 타입 오류로 빌드가 실패했다. 문자열 name의 기본 정확 일치로 수정했다.
- 브라우저 다크 레퍼런스에서 2/3열과 독립 호, 자정 이후 흐림, 단발 빨강/초록/흰색을 확인했다. 작은 버튼 포커스·disabled 및 삭제 배경 투명을 확인했고 버튼 32px·위험색을 실측했다. 라이트 레퍼런스에서도 겹침/자정/단발 색상을 확인했다. 실제 제품의 태스크 편집에서 상태 버튼이 없음을 확인했다. 모바일 390×844 제품에서 수정 버튼 높이 44px를 실측했고 크기 override는 복원했다. 실제 데이터 저장/삭제는 실행하지 않았다. 물리 터치 기기의 스와이프와 OS 모션 축소는 별도 검증하지 않았다.
- 최종 `npm run check:frontend` 통과: 문서/변경 게이트·포맷·ESLint·디자인/구조 검사·70개 파일 411개 테스트·TypeScript·Vite 빌드. 기존 500kB 초과 청크 경고는 유지된다. 백엔드는 이번 작업에서 수정하지 않아 재검사하지 않았다.
- 최종 diff·공백 오류 검토 후 기록과 문서 검사를 갱신했다. http://127.0.0.1:15173/#/today 및 http://127.0.0.1:15173/design-reference.html#today-dial-reference 화면과 개발 서버를 유지한다. 태스크 버튼 레퍼런스는 같은 페이지의 #task-actions-reference다.
