# Phase 7 검증 — 실행 체크·값·메모·완료

검증일: 2026-09-24

## 완료 범위

- 태스크 상태 PATCH와 시작/완료 POST, 세부 항목 값 PATCH, 일정 상태 PATCH.
- 필수 체크=true, 필수 텍스트=공백 아닌 값, 필수 숫자=유한 숫자(0 포함) 서버 검증.
- 완료 취소 시 completed_at 해제와 일정 상태 재계산. 건너뜀은 완료 체크와 구분.
- 필수 항목 삭제 시 완료 해제. 실행 중 변경은 원본 프리셋과 독립 스냅샷 정의를 유지.
- 항목 값·실행 메모 개별 저장, 저장 실패 시 초안 유지, 미저장 입력이 있으면 태스크 상태 변경 제한.
- Today 체크는 서버 성공 응답으로 갱신하며 필수 항목 부족 시 상세 입력 링크 제공.
- 일정은 모든 태스크 completed/skipped 시 자동 완료. 태스크 없는 일정은 명시적 완료 가능.
- 일정 취소/재개, 보관·취소 일정 실행 잠금, 일관된 400/404/409/503 오류.
- 새 migration으로 일정 pending→planned, skipped→cancelled 전환. ID·날짜·스냅샷·태스크 상태·실행값과 FK 보존.
