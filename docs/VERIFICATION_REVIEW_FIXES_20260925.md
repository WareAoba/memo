# 리뷰 후속 수정 검증 — 2026-09-25

## 변경

- Today의 날짜 기반 key를 제거했다. 편집·태스크 추가·저장 중 날짜가 바뀌면 현재 날짜의 목록과 입력을 유지하고 안내를 표시한다. 편집·추가를 닫거나 대기 중 저장이 끝나면 새 날짜를 즉시 조회한다. 날짜 변경 이후의 저장 응답도 원래 일정에 반영한다.
- 태스크 이름 저장 성공 시 서버가 반환한 이름으로 해당 입력만 갱신한다. 앞뒤 공백 때문에 미저장 상태가 남지 않으며 다른 메모·항목 초안을 초기화하지 않는다.
- 일정 상세에 생성 당시 워크 스냅샷의 custom_fields를 표시한다. 이름 없는 정보와 여러 줄 내용도 표시한다.
- 태스크 프리셋의 체크·텍스트·숫자 항목 추가/수정/정렬/삭제와 상세 조회를 복원했다. 필수 여부·기본값·숫자 단위를 지원하고 최대 100개로 제한한다. 기존 항목 ID를 유지하고 저장 시 순서를 재계산하며 종류 변경 시 호환되지 않는 기본값·단위를 비운다. 숫자 0과 빈 값(null)을 구분하고 저장 실패 시 초안을 유지한다.
