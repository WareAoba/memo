## 범위

- 사용자 확인에 따라 일정 제목=워크 이름, 하루 일정의 날짜 입력 생략을 의도된 UX로 명세에 기록했다. 해당 코드는 변경하지 않았다.
- 일간·월간·연간 캘린더 우상단 검색 버튼과 검색 모달을 추가했다.
- 전체 날짜에서 일정 제목·워크 스냅샷 이름·태스크 스냅샷 이름·일정 메모를 검색한다. 기본은 보관 포함이며 미보관/보관 필터, 20개 단위 페이지, 실패 재시도, 검색 변경 시 이전 요청 취소를 지원한다.
- 서버에서 검색·보관·소유자 필터를 페이지 처리 전에 적용한다. 검색 결과는 요약만 조회하며 결과 링크는 기존 일정 상세·복원 기능으로 연결한다.
- DB 마이그레이션은 없다.
